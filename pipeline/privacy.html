Privacy Policy

CriptoKnyght Pipeline · Effective October 15, 2026

Who this applies to

CriptoKnyght Pipeline ("the tool") is a personal tool used only by the owner of the CriptoKnyght YouTube channel, on the owner's own computer. It has no other users and no public sign-up.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

After the owner signs in with Google and approves access, the tool uses these permissions on the owner's own YouTube channel:

  • Manage your YouTube videos (youtube.upload): to upload finished episodes.
  • See, edit and delete your YouTube videos, ratings, comments and captions (youtube.force-ssl): to list the channel's own uploads (title, description, visibility, processing status, length), set thumbnails, add captions, and change a video's visibility when the owner asks.

The tool doesn't access other channels, comments, ratings, subscribers, analytics or any personal information beyond what is listed above.

How the data is used, stored and shared

  • Data is used only to edit and upload the owner's own videos.
  • The Google sign-in token is stored only on the owner's computer. The tool has no servers and keeps no copies anywhere else.
  • No data is sold, shared with third parties, or used for advertising or analytics.

Keeping and deleting data

The stored token stays on the owner's computer until it is deleted or access is revoked. Access can be revoked at any time at myaccount.google.com/permissions, which stops the tool from accessing the account. Video lists the tool reads are kept only as local working files for the editing process.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
